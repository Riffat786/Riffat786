## What I'm Exploring

Currently investigating how to make documentation:
- **Intelligent** — Self-updating with API changes, product releases
- **Maintainable** — Single source of truth, version controlled
- **Automated** — CI/CD integration, AI-assisted authoring
- **Connected** — Native to engineering workflows, not siloed


```text
Documentation
      ↓
Docs-as-Code
      ↓
Git + GitHub
      ↓
CI/CD + Automation
      ↓
APIs + Engineering Workflows
      ↓
AI-assisted Documentation
      ↓
Agentic AI + MCP
```

> **The goal isn't simply to use AI to write documentation.**
>
> The goal is to explore how documentation can become **intelligent, maintainable, automated and integrated with the way software is built.**
